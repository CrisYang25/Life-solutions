# 中国矿业大学校园网自动登录（Windows）

自动连接并认证 `10.2.5.251` 校园网（中国移动），认证后做**真实联网校验**，断网自动重连。
纯 PowerShell 实现，Windows 10/11 自带，**不需要安装 Python、浏览器插件或第三方软件**。

- 账号：填写在 `config.json` 里（学号，不带 `@cmcc`）
- 运营商：默认中国移动（`cmcc`，提交时自动拼成 `学号@cmcc`）
- 认证服务器：`http://10.2.5.251:801`

---

## 一、快速开始（3 步）

1. **确认账号**：用记事本打开 `config.json`，检查 `Account`、`Password`、`Carrier` 是否正确。
2. **先手动测试一次**：双击 `立即登录.cmd`。
   - 看到“认证成功，联网校验通过”，说明脚本可用；
   - 看到失败提示，按文末“常见问题”处理。
3. **安装开机自动登录**：双击 `安装自动登录.cmd`，在 UAC 窗口点“是”。
   - 安装完成后，每次登录 Windows 都会在后台自动运行；
   - 之后断网会在 30 秒内自动重连。

> 安装脚本需要管理员权限（用于创建计划任务、续租 IP）；登录本身不需要管理员权限。

## 二、文件说明

| 文件 | 作用 |
| --- | --- |
| `Connect-CampusNet.ps1` | 主脚本：检测网络 → 认证 → 联网校验 → 失败修复 |
| `config.json` | 账号、密码、运营商、门户地址等配置 |
| `Install-AutoLogin.ps1` | 安装 / 卸载计划任务（可带 `-DryRun` 预览） |
| `安装自动登录.cmd` | 双击安装（自动请求管理员权限） |
| `卸载自动登录.cmd` | 双击卸载 |
| `立即登录.cmd` | 双击立即登录一次，并输出详细日志（适合首次测试） |
| `查看日志.cmd` | 用记事本打开运行日志 |

运行日志默认在：

```
%LOCALAPPDATA%\CUMTNet\campusnet.log
```

（如果该目录不可写，会退回到脚本所在目录的 `campusnet.log`。）

日志超过 2MB 会自动轮转：旧文件改名为 `campusnet.log.1`，只保留这一份备份，磁盘占用最多约 4MB。日志可以随时手动删除，不影响脚本运行。

## 三、配置说明（config.json）

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `PortalHost` | `10.2.5.251` | 认证服务器地址 |
| `PortalPort` | `801` | 认证接口端口；不可达时会自动尝试 80 / 8080 |
| `Account` | 空（必填） | 学号（不要带 `@cmcc`） |
| `Password` | 空（必填） | 密码，原样填写，`@` 等特殊字符由脚本自动转义 |
| `Carrier` | `cmcc` | 运营商：`cmcc`=移动，`unicom`=联通，`telecom`=电信；也认“移动/联通/电信” |
| `Ssid` | 空 | 可选：校园 WiFi 名称。填写后，若没拿到 IP 会尝试自动连接该 WiFi |
| `IntervalSeconds` | `30` | 守护模式检测间隔（秒），最小 20 |
| `VerifyTimeoutSeconds` | `30` | 认证成功后等待联网生效的最长时间（秒） |
| `LogFile` | 空 | 自定义日志路径；留空使用 `%LOCALAPPDATA%\CUMTNet\campusnet.log` |

修改配置后需要重启一次后台任务才会生效（见“常见问题 7”）。

## 四、它到底做了什么

### 1. 认证接口

脚本调用的是学校 ePortal 网关的登录接口（与网页登录等价）：

```
http://10.2.5.251:801/eportal/?c=Portal&a=login
    &login_method=1
    &user_account=08266170%40cmcc
    &user_password=<密码>
    &wlan_user_ip=<本机IP>
    &wlan_user_mac=<本机MAC>
```

同时内置了新版接口 `/eportal/portal/login`，并会在“带本机 IP/MAC”和“由网关自动识别”两种参数之间自动回退，
以适配认证系统的不同版本。

### 2. 为什么能解决“WiFi 已连接但上不了网”

“已连接”只代表拿到了 IP，不代表认证会话有效。常见原因有：

- 电脑休眠 / 断线重连后，网关那边的旧会话已失效；
- 同一账号在手机、平板上登录，把电脑挤下线；
- 拿到了 IP 但根本没有完成认证；
- 认证成功但 DNS 缓存异常，或 IP 租约异常。

脚本的处理顺序：

1. **真实联网校验**：先访问 `connect.rom.miui.com/generate_204` 等探测地址，再校验百度/腾讯首页的真实内容，能识别“被劫持到认证页”的假联网；
2. 未联网 → 自动认证（新旧接口、两种参数自动回退）；
3. 认证接口返回成功但**仍然上不了网** → 自动“注销 → 重新认证”（解决会话残留、账号被挤下线）；
4. 仍失败 → 刷新 DNS 缓存；有管理员权限时再续租 IP，然后重新认证；
5. 守护模式每 30 秒巡检一次，失败后按 30s → 60s → 120s → …（最多 5 分钟）退避重试；
6. 如果服务器明确返回“密码错误/账号不存在”，**立即停止重试**并写日志，避免账号被锁。

### 3. 计划任务

- 名称：`CUMT校园网自动登录`
- 触发：当前用户登录 Windows 后延迟 10 秒
- 权限：最高权限（这样才能续租 IP）
- 行为：后台常驻，单实例运行（重复启动会自动退出）
- 电源：电池/交流电都运行，不会因为省电被停止

## 五、常用命令

在脚本目录打开 PowerShell：

```powershell
# 立即登录一次（详细日志）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Connect-CampusNet.ps1 -VerboseLog

# 只做诊断，不登录（排查“连上了但上不了网”）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Connect-CampusNet.ps1 -Diagnose

# 强制认证一次（切换账号或排查问题时）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Connect-CampusNet.ps1 -Force -VerboseLog

# 前台守护（调试用，Ctrl+C 退出）
powershell -NoProfile -ExecutionPolicy Bypass -File .\Connect-CampusNet.ps1 -Watch

# 查看计划任务状态
Get-ScheduledTask -TaskName 'CUMT校园网自动登录' | Get-ScheduledTaskInfo
```

诊断输出包含：网卡/IP/MAC/网关、WiFi、DNS、门户 80/801/8080 端口、门户首页关键字（eportal/srun 等）、联网探测结果。
如果学校以后更换认证系统，把诊断输出和日志发出来即可快速适配。

## 六、常见问题

**1. 提示“认证服务器 10.2.5.251 的 80/801/8080 端口均不可达”**

- 当前不在校园网：先连接校园 WiFi 或插网线；
- 如果连的是手机热点/家里宽带，这是正常现象，脚本不会做任何事；
- 校园 WiFi 需要网页认证时，先打开浏览器访问任意网站，确认能弹出登录页。

**2. 提示“服务器拒绝了账号或密码”**

- 检查 `config.json` 里的 `Account`、`Password`；
- 确认运营商选对：移动 `cmcc`、联通 `unicom`、电信 `telecom`；
- 密码就是上网密码，不是统一身份认证密码；如果刚改过密码，同步修改配置；
- 连续多次失败可能触发学校风控，建议先在浏览器里手动登录确认账号正常。

**3. 认证成功，但还是上不了网**

脚本已经会自动注销重登、刷 DNS、续租 IP。若仍失败：

- 运行 `Connect-CampusNet.ps1 -Diagnose`，看“联网探测”和“门户首页”结果；
- 确认账号没有欠费、没有被学校限制；
- 确认没有同时用手机登录同一账号（会被挤下线）；
- 如果开着 VPN、代理或加速器，先退出再登录（`10.2.5.251` 是内网地址，代理可能让认证请求走错线路）；
- 尝试在浏览器里手动打开 `http://10.2.5.251/`，看是否能正常登录/注销。

**4. 提示“用户已在线/达到在线数上限”**

脚本会自动注销再重登。如果反复出现，先在浏览器登录页点“注销”，或把其它设备下线。

**5. 休眠唤醒后要等多久？**

最多 30 秒左右会自动恢复；也可以在唤醒后双击 `立即登录.cmd` 立即触发。

**6. 怎么确认后台任务在跑？**

```powershell
Get-ScheduledTask -TaskName 'CUMT校园网自动登录'
```

状态应为 `Running`。也可以打开“任务计划程序”查看历史记录。

**7. 修改密码/换运营商**

改 `config.json` 后，后台任务需要重启才会读取新配置。最简单的办法：重新双击 `安装自动登录.cmd`（会覆盖安装并重启任务）。

**8. 卸载**

双击 `卸载自动登录.cmd`，会停止并删除计划任务；脚本文件可直接删除。

**9. 把文件夹挪到别的位置了**

计划任务里记录的是脚本的绝对路径。移动文件夹后重新双击 `安装自动登录.cmd` 覆盖安装即可。

## 七、安全提示

- `config.json` 里是**明文密码**，这是唯一保存账号信息的地方。分享脚本前请删除或清空它；`Connect-CampusNet.ps1` 本身不含任何账号密码。
- 可以限制配置文件权限（可选，在脚本目录打开 PowerShell）：

  ```powershell
  icacls .\config.json /inheritance:r /grant:r "$env:USERNAME:(R,W)"
  ```

- 脚本只向 `10.2.5.251` 发送认证请求，联网探测只访问 `connect.rom.miui.com`、`wifi.vivo.com.cn`、`www.baidu.com`、`www.qq.com`，不收集、不上传任何数据。
- 运行日志会记录学号（不含密码）；把日志发给别人排错前请留意。

### 分享给别人

可以分享，只要**不要带上自己的 config.json**：

1. 把 `config.json` 删除或清空，或让对方使用 `config.example.json` 改名成 `config.json`；
2. 其余文件（`.ps1`、`.cmd`、`README.md`）都不含账号密码，可以放心发送；
3. 对方填好自己的学号、密码后，双击 `安装自动登录.cmd` 即可。

> `config.example.json` 是空白模板，账号密码为空；未填写就运行会提示“未配置账号或密码”。

## 八、兼容性与限制

- 适用于 Windows 10 / 11，使用系统自带的 Windows PowerShell 5.1；
- 需要能访问 `10.2.5.251`（校园网内）；
- 如果学校把认证系统整体换掉（例如改成深澜 Srun、需要验证码、需要 HTTPS 客户端证书），脚本需要相应调整——先跑 `-Diagnose` 留存输出；
- 本脚本按“学号@cmcc”方式认证；若学校要求其它后缀，改 `Carrier` 或直接把 `Account` 写成完整账号（脚本检测到 `@` 就不会再拼接）。
